# Site Ολυμπιακού

Ανεπίσημο ενημερωτικό site για όλα τα τμήματα του Ολυμπιακού.

- `news.html` — ειδήσεις Ολυμπιακού από όλα τα αθλητικά sites (ανανέωση κάθε 15 λεπτά μέσω GitHub Actions)
- `scripts/fetch_news.py` — ο συλλέκτης ειδήσεων (μόνο Python standard library)
- `data/sources.json` — οι πηγές· για νέα πηγή προσθέτουμε μία γραμμή
- `data/history/` — ιστορικά αρχεία: Super League (1994–σήμερα), Euroleague (2000–2025) και box scores παικτών (2010–2025)
